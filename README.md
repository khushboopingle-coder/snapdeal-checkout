# 🛒 Snapdeal Checkout Flow — Redesign

> This is a **UI/UX Redesign Task** of the Snapdeal e-commerce checkout flow. The original checkout was redesigned to improve user experience, visual clarity, and modern design standards.

---

## 📌 Task Overview

| Detail | Info |
|--------|------|
| Type | UI Redesign Task |
| Platform | Snapdeal (E-commerce) |
| Page | Checkout Flow |
| Tech Used | HTML, CSS, JavaScript |

---

## 🔄 What Was Redesigned

- **4-Step Checkout Flow** — Details → Delivery → Payment → Confirmation
- **Clean Progress Bar** with active/done step indicators
- **Contact & Address Forms** with proper validation styling
- **Shipping Method Selection** (Standard / Express)
- **Payment Methods** — Card, UPI, Net Banking
- **Live Card Preview** that updates as you type
- **Order Summary Sidebar** with real product images
- **Order Confirmation Screen** — centered layout with order details
